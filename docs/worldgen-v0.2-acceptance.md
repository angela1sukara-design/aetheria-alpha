## 可运行交付

`Aetheria-WorldGenerator-v0.2.zip` 包含源码、内容与规则JSON、文档、测试，以及 `dist/` 可运行构建。无需安装依赖即可直接打开以下离线文件：

| 文件 | 内容 |
| --- | --- |
| `dist/Aetheria-Alpha-0.2.html` | 固定测试世界及随机街区菜单 |
| `dist/WorldGenerator-Seed-7.html` | 晴砾街区，7地点、9居民 |
| `dist/WorldGenerator-Seed-42.html` | 林荫街区，7地点、9居民 |
| `dist/worlds/seed-7.json` / `seed-42.json` | 各自完整初始存档 |
| `dist/worlds/manifest.json` | 种子、规模、生成版本及内容来源 |

两份世界的布局、生态和居民分布不同。具体玩法与未来词条接入见 `world-generator-v0.2.md` 和 `worldgen-lexicon-integration.md`。
