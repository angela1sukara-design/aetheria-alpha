# 第三阶段：固定 NPC、日程与记忆

授权：用户已试玩并要求直接继续。沿用独立 TypeScript 工程，不复制旧 Demo 代码。

来源核对：Notion《架构修订 v0.2》《Claude 接续说明》全文，以及《以太都市_重构版游戏策划与开发规格书_v3.0.md》10.1/10.3。保留薇尔维特（velvet）作为沙龙经营者，增加沙龙这一既有地点；不扩写出身、政治势力或秘密。年龄、精确身体构型尚无确定数据，不填虚构年龄或人体图；普通交谈可运行，成人事件继续不可加载。09:00–18:00 柜台、18:00–19:00 集市等日程、对白、核对订单小委托和关系数值均为 PROPOSED 试运行内容。

本轮范围：第五地点沙龙；一位固定 NPC 的分时日程、真实多节点谈话、一次跨地点核对清单委托；熟悉/信任与结构化记忆；人物入口、当前在场人物、已结识人物档案。正常生活、耳/尾自由 TF 和机械尾分阶段改造保留。

最小协议：`SpeciesDef / NPCDef / NPCMemoryDef` 为只读定义；GameState 增加固定 NPC 实例（稳定 ID、discovered、关系向量、带时间/来源事务的记忆）。位置纯按时间派生；活动事件参与者暂留在事件现场，退出恢复日程。NPC 话题使用公开 action Hook，由同一个选择器授权。`npc.present / npc.memory / npc.relation` 和 `npc.remember` 走统一 DSL；一个事实只结算一次关系，不靠重复问候刷好感。集市核对事实先记玩家旗标，回来展示结果后 NPC 才记住，不能远程全知。

新增官方世界子包 `aetheria/social`；保持前3包内容和 hash 不变。存档 schema 3：精确支持发布的 stage1/stage2 官方指纹升级，旧字段完整验证；为新模块增加默认数据，并保留已有身体、TF、时间、事件、RNG 和账本；升级成功只在内存，手动保存前不覆盖旧槽。

验收：日程边界/跨午夜/事件临时覆盖；条件和权威授权；重复谈话/重复交付/旧请求重放不刷关系奖励；原子回滚；NPC 不能获得没看见的事实；完整存读与 stage1/2 精确迁移；公开话题 Hook 扩展、乱序加载稳定；真实浏览器桌面/390px、日程等待、委托、关系面板与旧档启动升级。

本轮停止点：以上闭环验证并交付后停止。不实现路人随机/晋升、完整个人攻略线、InteractionScene、装备或战斗；不宣称 M1/M2 已全部完成。
