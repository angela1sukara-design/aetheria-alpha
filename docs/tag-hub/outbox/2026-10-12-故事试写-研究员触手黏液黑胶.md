# 试跑稿｜触手黏液→黑胶化

## 1. 场景正文

培养槽的盖沿仍挂着未干的水珠。深夜的实验室只剩日光灯嗡鸣。林澄——白大褂袖口挽到肘上的女研究员——把记录板搁在台边，护目镜推上额头。槽内半透明的触手黏液正缓慢起伏，像在等她靠近。

她俯身核对编号。一条细触须探出液面，缠上她的手腕内侧。黑胶初触凉：弹性薄膜贴住脉搏，凉意先到，随即带一点黏。她缩手，触须跟着收紧，在脉搏处勒出浅痕。

采样镊还差半寸。第二、第三条触须溢出槽口，缠绕前臂向上爬。触手黏液在皮肤上涂覆，发出细微啧声，每贴合一寸就多一层压迫。她后退，椅脚刮地——更多黏液从槽壁溢下，滴落包覆她的白大褂下摆，再顺着裤管往脚踝流。

脚踝先被缠住。黏液透过袜面贴上踝骨，凉意迅速被紧绷取代：胶质变稠、变暗，由半透明转为深灰。局部黑胶化在这里启动——那一片不再流动，而像半硬化黑胶，随着她试图抬脚而油亮反光。鞋面外沿也被同一股黏液涂覆，缝隙逐寸收死，却仍是袜子与鞋的轮廓，只是外层开始发黑发亮。

她咬唇，指尖抠向踝上那层膜。指甲陷进去又弹开；抠开的缝隙立刻被新的触手黏液填满、压平。黑胶塑形中：纹理细密，脉动未停，表面却已接近活体黑胶的光泽。再往里探，指腹触到更硬的一层——硬化黑胶的边缘，短、薄，却已不回流。

膝弯是下一处。黏液沿小腿内侧上行，在膝窝汇聚、涂覆，再往大腿内侧蔓延。裤料被浸透。大腿内侧的皮肤先黏液化——湿冷、滑腻——再被收紧、压暗，局部黑胶化把那一带裹成油亮的黑条。活体黑胶浸染沿着已成形的边缘推进，一寸寸改写触感。每一次想并拢双腿，半硬化黑胶就会在膝弯吱一声轻响，提醒她活动范围正在缩小。

触手继续向上。腰侧、后腰——每到一处先缠绕，再涂覆，最后滴落包覆尚未硬化的边缘。白大褂前襟被扯开一角，黏液顺着锁骨窝流下。呼吸被勒浅。她听见自己喉咙里的短促气音，以及黏液与黑胶交接处细碎的撕拉声。

一条较粗的触手绕上颈侧。黏液贴住耳廓，做封口包覆：世界忽然远了一截，走廊空调的嗡鸣变钝，心跳的撞击却异常清晰。感官像被这层膜滤过——触觉放大，听觉发闷。她抬手去扯，指尖已裹着半硬化黑胶，关节弯折时咯吱轻响。

培养槽核心仍在脉动。新的触手黏液顺着已成形的活体黑胶表面爬行，寻找缝隙：锁骨、乳下弧线、指缝。每填满一处，那一块就先黏液化，再进入黑胶塑形中，最后定成油亮、微凉的黑胶。黑胶化并未一次完成全身，全身黑胶覆层还远，黑胶硬化完成也只发生在踝侧那一小片；其余仍是刚硬化与仍湿软的交界。

膝盖发软。触手托住她又往下滑，后背蹭过实验台边缘，黑胶与金属摩擦出细响。腿间未完全转化的皮肤仍在抽动；黏液往那里汇聚，带来一阵阵酥麻，迫使她弓腰。肌肉每绷紧一次，尚未硬化的黏液就更快贴合、更快变暗——黑胶化在加速。

她把额头抵在已发黑发亮的小臂上。呼吸打在油亮表面，凝成薄雾又散。后颈又覆上一层触手黏液，缓慢、耐心，像在完成下一道工序。

## 3. 可玩节点草图

### 节点 A｜脚踝局部黑胶化
- **触发**：触手黏液缠踝；局部黑胶化开始
- **choice**：抠膜拖延 / 抬脚挣脱（可能加速） / 观察记录（换部位）
- **exit**：→ B；挣脱离开 → 待封装

### 节点 B｜膝弯→大腿内侧
- **触发**：过膝弯；大腿内侧黏液化/局部黑胶化
- **choice**：并腿拖延 / 够急停（不确定） / 引导改涂小腿
- **exit**：→ C

### 节点 C｜颈侧封口包覆
- **触发**：封口包覆；感官滤波
- **choice**：「先别封口」 / 接受封口 / 前臂挡溢流
- **exit**：封口→感官衰减；未封口→可呼叫

### 节点 D｜抵抗加速 vs 放松拖延
- **触发**：绷紧加速贴合
- **choice**：挣扎加速 / 放松拖延 / 以硬化踝撬膝弯
- **exit**：高进度逼近全身覆层；低进度回 B

### 节点 E｜离开培养槽（可选）
- **choice**：冲门 / 关盖 / 仪器记录冻结
- **exit**：离开后续接待封装

## 4. 待封装玩法

- 抵抗反噬（挣扎→加速黑胶化）

- 离开后续接
- 急停控件（不确定）
