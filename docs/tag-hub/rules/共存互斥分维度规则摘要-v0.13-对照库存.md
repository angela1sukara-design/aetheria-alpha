## 2. 可执行规则摘要（按维度）

每维：**短表** + **禁例**。状态默认「编辑约定」，另注已实现/待接入。

### 2.1 一条一事 / 一主分类

| 规则 | 口径 |
|---|---|
| 一条一事 | 一原子一事；整场戏 / 手术+性交 / 剧情段 **拆多条** |
| 一主分类 | `category` = batch `library`；跨库相关用说明/`usage`/人工对照，不造无关假同名 |
| 场景靠组合 | 组合公式只指导编辑，≠运行时自动拼装协议 |

**禁例**：一条写完「切开→置换→再性交」；把「缰绳+黑胶+死死+挂住」揉成不可检索混装原子。

### 2.2 通用 vs NSFW；词条 vs 运行时包

| 规则 | 口径 | 状态 |
|---|---|---|
| format/library **互斥混装** | 通用 `aetheria-lexicon-batch` ≠ NSFW `aetheria-nsfw-lexicon-batch`；禁止跨前缀塞条 | 双方；通用校验**已实现拒绝** NSFW format |
| 词条 batch **互斥互导** 运行时包 | 不与 ContentPack / TextExpansion / ReferencePack 混装互导 | **已实现**隔离 |
| 收录→审定→接入→本局→玩法 | 状态机分离；AI 不得自带 `approved` | 通用流程已实现；NSFW 自动路径**待接入** |

**禁例**：NSFW 条塞进 `body-*` batch；把 lexicon batch 当 ContentPack 导入；声称「已入库＝玩法已实现」。

### 2.3 material ∥ fluid；定词挂前；黑胶 / 黏液 / 凝胶

| 规则 | 口径 |
|---|---|
| 跨类实体 | 主定义常落 **material**；液态用法 **fluid** 分挂；`usage` **仅提示**，不能唯一定位主定义（§5.4） |
| 定词挂前 | `定词 + 黏液/黑胶/…`（触手黏液、蛞蝓黏液、史莱姆黏液…）；定词 ≠ creature 本身 |
| 分立互斥（语义） | **黑胶 ⊄ 黏液 ⊄ 凝胶**；可并存描写，**禁止 synonyms 互充** |
| gear vs material | 器具 ≠ 材质本体；「黑胶缰绳」应可分检索 |

**禁例**：用黑胶条顶替蛞蝓/触手黏液（或反之）；把触手 creature 与黏液 material 混成一条；只建「黑胶缰绳」混装条而无材质/器具分账。

### 2.4 goo / 黑胶化（通用 tf 组合）

| 规则 | 口径 |
|---|---|
| 范式 | 活体黑胶(material) + 黑胶化(tf) + 可选 state/kink + 已有对象指向 |
| 主体不限 | 生物/物品理论上都可写 goo；**不为物种/物件建「××黑胶化」** |
| 转化仍通用 | `黑胶化` / `黏液化`；定词只修饰材质来源，不枚举「狐黏液化」「桌黑胶化」 |
| goo转化 英文别称 | 对齐已有「黑胶化」；**勿双主定义**（建议 synonyms/tags，待审） |

**禁例**：研究员黑胶化 / 触手黑胶化 / 培养槽黑胶化专条；水生黏液化等定词 tf 专条（应用通用黏液化+定词材质）。

### 2.5 kink ≠ state ≠ 意愿；gore

| 维度 | 写什么 | 不写什么 |
|---|---|---|
| **kink** | 偏好（喜欢什么）；**必填** `tier` | 当场进行态；同意检查 |
| **state** | 当下现场态 | 长期偏好 |
| **意愿/合意** | 事件条件 / 记忆 / 旗标 / 情境正文 | **不是** 14 库独立 library；勿用条目 tags「已同意」 |
| 性癖与拼装 | kink **不进**拼装槽；仅编辑选材参考 | 「性癖决定动作」自动机制 |
| gore | `tier: gore` **默认不强产** | 用户未点名时批量造 gore |

**禁例**：把「正在截换」写成 kink；把「喜欢公开」写成 state；把「先别封口」口语建成意愿 kink。

### 2.6 action ≠ tf ≠ state；pose

| 规则 | 口径 |
|---|---|
| action | 可执行动词原子（勒、挂住、楔入、顶入、内射…） |
| tf | 转化/改造过程或结果；可配 `phase`（建议字段，是否强制**待制定**） |
| state | 挂住未拔、改造进行中等现场态 |
| pose | **俗称 `name` + 必填 `precise`**；粗类 ≠ 已有「××后入/口舌」细条 |

**禁例**：tf 条只写「摸一下」；pose「四足趴地」冒充已有「四足后入」；粗类 pose 与动作细名混库。

### 2.7 creature ≠ part；种族称呼 ∥ 形态

| 规则 | 口径 |
|---|---|
| part | 可指向身体目标/结构 |
| creature | 影响情色互动的形态特征；≠完整种族档案；≠纯外观无互动（偏通用 `body-*`） |
| 种族称呼 ∥ 形态 | 如「狼根」∥「马屌」可并列；**禁 synonyms 互充** |

**禁例**：creature 冒充 part 目标；把形态词塞进种族称呼 synonyms；复制 `body-beast` 进 NSFW 充数。

### 2.8 身体两层视图；≠ BodyGraph

| 层 | 视图 | 状态 |
|---|---|---|
| SFW | 通用 `body-*` | 素材分类**已实现**（目录/校验） |
| NSFW | `nsfw-part` / `creature` / `genitals` 等 | 分类**编辑约定**；自动校验**待接入** |
| suggestive | 草案，**不另开 library** | **无正式运行字段**（§12.2） |

- **不共享 id**；跨层用检索/标注/人工对照。  
- **BodyGraph** 才是真实身体；素材可超前，不得假装部位/玩法已实现。  
- 字段级对照表 **尚未确定** → 不编造映射表。

### 2.9 foundation 题材 Tag（只表题材）

来自 `foundation-tag-mapping.md`（tag-effect-preview）：

| 规则 | 口径 |
|---|---|
| 故事主题「黑胶 / TF / 机械 / 夜间」等 | **只表题材**，**不证明**当前身体材料、形态、TF 进度或真实时段 |
| 别名 | **不跨域等同**身体状态；不把同词题材自动等同 material/tf |
| 派生 Tag | 查询派生（如 has-tail、time.night）；字典不含概率/TF 效果/可变状态存档 |
| 湿润/干燥等 | 环境预设语义，不宣称真实温湿度 |

**禁例**：挂上 `foundation:theme.gel` 就当作已有活体黑胶 material 或黑胶化进度；用 foundation 字典冒充 NSFW/通用词库全集。

### 2.10 字段分列（不得混用冒充）

| 维度 | 用什么 | 不可代替 |

## 5. 给下游 bot 的一页检查清单（≤10，yes/no）

色图抽条 / 补库 / 查缺前自检：

1. **一条一事 + 一主分类？** 未把整场戏或混装原子写成一条。  
2. **通用 / NSFW format·library 未混装？** 词条 batch 未冒充 ContentPack / TextExpansion。  
3. **material ∥ fluid 跨类实体？** 主定义在一处；`usage` 仅提示；定词挂前且定词≠creature。  
4. **黑胶 ⊄ 黏液 ⊄ 凝胶？** 未用 synonyms 互充；未用黑胶顶替定词黏液。  
5. **goo/黑胶化是否通用组合？** 未建「××黑胶化/××黏液化」物种或物件专条。  
6. **kink ≠ state ≠ 意愿？** kink 有 `tier`；意愿未写进条目 tags；性癖未当拼装槽。  
7. **action ≠ tf ≠ state？** pose 有 `precise`；粗类 pose 未冒充已有「××后入/口舌」。  
8. **creature ≠ part？** 种族称呼 ∥ 形态未互塞 synonyms。  
9. **身体两层视图不共享 id？** 未把素材分类写成 BodyGraph/已实现槽位；foundation 题材 Tag 只表题材。  
10. **字段分列清楚？** kink tier / contentTier / 年龄 / 意愿 / 显示偏好未混用；未编造未确认互斥矩阵；未声称已验收/已实装。
