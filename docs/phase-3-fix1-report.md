# 第三阶段自检与修复报告

日期：2026-10-11。版本：`0.1.0-alpha.3.1`。基线：第三阶段提交 `9b622ec897e40f5114ac47afcd0c8598e547354a`。本次只修复第三阶段，不开展后续玩法。

## 复现结论

任务完成不会删除薇尔维特。真正导致“看起来消失”的情况是：谈话保留NPC在当前场景，结束时恢复日程；18:00后去集市，19:00后离开公开场所。原UI把不在场人物卡和交谈入口一起隐藏，结束文字却没有去向或再会说明。

| 原版真实操作复现 | 结束后位置 | 人物与任务事实 | 原界面表现 |
| --- | --- | --- | --- |
| 白天10:35完成委托并退出 | 薇尔维特沙龙 | 同一人物、已结识、交差记忆保留 | 仍能继续交谈 |
| 谈话跨18:00，18:05退出 | 集市 | 同一人物与交差记忆保留 | 沙龙人物卡及交谈入口消失，退出文字未解释 |
| 谈话跨19:00，19:05退出 | 暂无公开位置 | 同一人物与交差记忆保留 | 人物卡消失，未提示次日09:00再会 |

复现记录在 `artifacts/npc-audit-before.json`。未取得玩家当时的存档和时钟，因此这是已复现的原因，不假定已覆盖玩家可能遇到的所有情况。

## 已修复

| 问题 | 修复后的实际行为 |
| --- | --- |
| NPC离场无说明，容易误认为被任务删除 | 成功事务比较行动前后位置，记录真实离场/到场和最早再会；事件参与者仍在交谈中暂留；失败、重绘和玩家自己旅行不伪造离场 |
| 离场后原场景没有人物线索 | 已认识且在此有日程的人物保留卡片，显示当前去向、最早公开会面，以及必要时返回当前地点的时间 |
| 人物档案缺乏再访操作 | 在场且无活动事件时提供由统一选择器授权的真实话题入口；开启交谈后关闭人物面板；不在场时可打开地图查询 |
| 地图人物信息不足 | 地图显示已认识人物的公开去向；离场时显示再会时间；导入尚未认识NPC的存档会清空旧显示 |
| 沙龙精力耗尽后无法返程 | 追加沙龙休息行动：免费、30分钟、精力+10；真实推进时间与TF，随后可返程和回公寓恢复 |
| 无条件直接扣精力动作显示可用，点击才失败 | 选择器预检可确定的直接扣费，按执行顺序累计并遵循上限；不足时按钮禁用并解释。节点进入/TF付款等边界后不猜测资源，仍保留完整事务回滚 |
| 服务器显示过时阶段名 | 启动输出读取当前包版本，便于确认正在运行修复版 |

没有复现“诊室零精力出不去”：诊室返程原本不扣精力，本次保留并回归验证。

## 模块与存档边界

- 日程、姓名、经营者身份、已有四包JSON内容均未改。只读NPC查询不推进时钟、消费RNG或写人物实例。
- 休息内容位于独立 `content/recovery/pack.json`，通过沙龙公开Hook追加；没有把内容或特例写进HTML、人物分支或旅行引擎。新增恢复数值为PROPOSED试运行内容。
- 官方已发布的Stage1/2仍精确升级。原Stage3四包存档升级只追加恢复包引用：身体、TF、人物身份/关系/来源记忆、任务、事件、时间、RNG和整个账本逐字段保留，schema仍为3。
- 读取、导入不会覆盖手动槽，点击保存才写入修复版。原四包Registry读取自身匹配的存档不触发额外升级。
- 修改过的包、未知字段、坏身份/记忆即使重新计算checksum仍会隔离，原字符串保留。修复版五包存档不能返回原四包引擎；未实现通用第三方包迁移。

## 使用与范围

关闭上一版黑色服务器窗口，把修复ZIP解压到新文件夹，双击 `start_game.bat`。继续使用原浏览器与 `http://localhost:4173/` 即可读取同来源手动存档；更换浏览器或地址时通过旧版导出JSON、本版导入。包内带构建好的 `dist/`，试玩无需安装开发依赖。

本轮没有增加新NPC、新任务线、战斗、完整姿势、装备或后续阶段。自检重点是上述可执行链路；不宣称全库无缺陷。Windows批处理未在本Linux环境原生执行，游戏服务器和实际网页交互已验证。
