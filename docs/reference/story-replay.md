# 故事复刻运行约定

车道：`mechanism`。本次扩展现有 Event 与 narrative，不新增第三套场景状态，不改 A/B 模板或词库。内容作者使用已装入的新字段后，可继续按 `content` 车道交付。

## 从故事到内容

先拆出约 3–5 个真正需要决定的拍：正文写完整场景，环境并入当前段落，最后落在冲突。节点数与字数是编辑目标，不用纯观察、二次确认或无效按钮凑数。普通观察只有在改变信息、风险或路线时才成为行动。

正文使用完整段落。Tag 与属性负责找真实场地、在场人物、适用段落和后果，姓名等少量信息填入正文。未编写或不支持的组合使用明确的普通回退，不能声称无限生成所有故事。

有绑定的事件正文独立成段，在冲突与选择处结束；地点氛围仍可从地点介绍读取，不再追加在事件正文末尾。

## Event 的声明与快照

使用 `event.context.v1` 能力：

- `binding.environmentTags`：当前地点须具有全部已注册 Tag。不会把玩家传送到一处虚构场地。
- `binding.resident.tags`：选择当前地点的真实居民，按结构化性格 Tag 匹配；可加 `service`（与 `service.available` 相同的 resident 要求）。职业称呼不替代服务和设施。
- `binding.enemy: "environment"`：复用环境选敌规则，一次选定实际规则、敌人和其声明的组合池；后续战斗使用同一对手，不重新抽取。
- `binding.partKind`：绑定玩家真实存在的部位，缺少该类部位时入口不出现。

以上查询不消费 RNG。真正提交入口时，把来源 ID 和显示填充保存到 `EventInstance.context`。重绘与读档不重选演员。`{place}`、`{resident}`、`{opponent}`、`{part}` 等只读取已保存绑定；敌人没有声明材质池时不随机发明材质。未知占位符使事务失败。

节点的 `textCases` 为按顺序匹配的完整段落：`{when: Condition[], text: Id, onEnter: Effect[]}`。未匹配时使用原有 `textVariants`。分支可查询资源、真实身体、环境、`opponent.matches` 和 `narrative.tag`。`tf.available` 只读预检既有 TF 能否实施，不把未知材质当成未覆盖、不消耗资源。

选中的文本 ID 仍保存在 `textByNode`；条件效果与公共 `onEnter` 都只执行一次。事务的 `eventEntries` 保存所选事件、节点和文本，供 TF 来源和历史归档校验，不能拿任意分支效果冒充真实来源。

## 跳过、撤离和战斗

每段都必须能在资源耗尽时推进或结算，允许失败、受困或等待处置。加载时不再要求每段直达免费出口。`var.compare` 仍是行动门槛，不满足不会自动转入失败分支；失败或保底路径须明确写出。

Event 的 `skipActionId` 必须引用该节点唯一正常后续行动的结算别名：条件与 effects 完全相同。不能在有多个剧情选择的节点用跳过代替决定，也不能省去覆层、标记或耗时。

narrative 的 `skipChoiceIndex` 标记无条件且有下一阶段的过程行动。只有它是当前唯一可执行选择、且没有可用的属性反应时才提供跳过；其他条件分支或反应可用时立即停下。`narrative.skip` 逐步执行这些普通行动，保留其效果和随机记录，到下一决策点停下。缺失后续正文会回滚并报缺，不再静默结束故事。

节点可声明 `combatOutcomes: {victory, defeat, escape}`，用本事件内节点 ID 对接常规战斗。没有声明时不允许在事件里开战。战斗结束回到相应节点；战败当场仅做已声明的身体、伤势与残迹结算，心性分支仍由玩家事后自选。G/C 编号本身不是 opcode。

`event.exit` 只结束事件。若需要跨地图回安全点，必须使用真实路线和相应代价；本次样例只撤回当前地点的路沿或公共通道，不虚报回家。

## 内容与构建

`scripts/build-story-content.mjs` 是作者源，输出 `content/story-replay/pack.json`；默认内容索引已登记。两个入口分别要求湿地环境及工坊真实工作服务，条件不成立则隐藏。正常游玩成人偏好保持关闭也能完成。

运行 `node scripts/build-adventure-content.mjs` 后，再运行 `node scripts/build-story-content.mjs`，最后按构建流水线更新运行入口。新故事不改 `content/core/pack.json`。

旧生成世界读取自己的包快照，保留旧正文、地图、人物与进度，不注入新绑定。固定旧档仍按精确包指纹校验；不匹配时保留并隔离，不放宽检查。本次没有改变世界形状或生成器版本。

## 缺口与边界

- 当前支持作者准备的完整段落及属性分支；没有运行时自由写作模型。
- 示例复用现有下肢覆层补丁；部位或队列不适配时使用不声称覆层已发生的普通结算。多回合闭气、NPC 临场倒戈未封装。
- C 类展示槽位不能自动当作身体效果；有规则的 G 类与 TF 需要明确入口和 effects。
- 没有新增正式 Tag 或修改字典；今后的候选 Tag 只报待入库，不与已注册引用混用。
