# v11 这一轮怎么装

装进 Gemini 正在改的 **v11 单文件 HTML**。不要装进这个仓库的旧工程。

标签全文在 [角色标签](character-tags.md)。这一轮只装下面列出的部分。

## 装什么

1. **场所分成两类**
   - 功能场所：进门是场景描述和对话。只有选了事件，才进入和这个 NPC 的战斗。没选事件时不出现战斗，也不刷野怪。
   - 战斗场所：进门是场景描述，然后只有战斗。不放治疗、打造、交谈。
2. **四个世界都改场所。** 原来的诊所和工坊改成功能场所，原来的人留在对话里，战斗收进一条事件。原来的危险房间和首领房间保持战斗场所。
3. **奇幻世界加上十八个功能场景。** 正文用下面的 summary。对话每条一两句。只有旧城医院、七灯酒馆、巡林站可以写「事件进入战斗」。
4. **材质和形态标签。** 每个敌人和 NPC 记 `materials` 和 `forms`，界面上能看见。不因此重写战斗结算。
5. **八个身体部位。** 只改名单和归类，不重写技能公式。

## 这一轮不装

尺寸四档的具体用词。吞噬、附身、寄生的结算。主线正文。道具。战斗举例属性里留哪些。态度拆不拆。另外五十六个备选场景。

## 怎么装

把下面整段贴给 Gemini，连同 v11 的 HTML。

```text
继续 v11。按下面的范围改，不要重写战斗公式和八槽拼句。

一、场所

功能场所（现在的 SAFE_CLINIC、WORKSHOP）：
进门先显示场景描述，然后是对话。
对话至少有招呼，以及这个场所真正提供的功能。
只有玩家选了某条事件，才进入和这个 NPC 的战斗。
没选事件时不出现战斗按钮，也不刷野怪。
原来站在诊所和工坊里的人留下来当对话对象，不要删除。

战斗场所（现在的 HAZARD_1、HAZARD_2、BOSS_CHAMBER）：
进门是场景描述，然后只有战斗。
不写治疗、打造、交谈。

四个世界都按这个改。

二、奇幻世界加上这十八个功能场所

场景描述用给出的 summary。每个场所补对话，每条一两句。
治疗场所只提供治疗。工坊只提供打造或修缮。旅馆和酒馆只提供休息、吃饭和交谈。
广场、码头、林地、星象台只提供观看和交谈，不要硬加功能。
只有旧城医院、七灯酒馆、巡林站写「事件可以进入战斗」。
战斗场所仍用奇幻世界原来的地穴、巡猎道和王座，不要把战斗写进这十八个场景。
不要加主线，不要加道具。

石环旧城
- bellplaza 晨钟广场：宽阔的石板广场围绕着古老钟楼展开，地面上留有历代修缮时拼接的不同颜色石材。清晨有居民在这里做操，午后则是孩子追逐、老人闲聊的地方。整点钟声响起时，广场上的鸽群总会同时飞起来。
- clocktower 大钟楼：高耸的钟楼几乎能从城镇任何地方看见，内部盘旋的楼梯一直通往顶层。负责维护钟楼的工匠每天都会上去检查，有时也允许居民登高眺望。风大的日子里，整座塔楼都会发出低沉的嗡鸣。
- cityhall 市政厅：这座灰白色建筑有着宽大的拱窗和常年敞开的前厅，墙上贴满城镇公告。职员们忙着处理居民登记、街道修缮和各种邻里纠纷。偶尔有人为了排队顺序吵起来，负责接待的老人总能让他们安静。
- oldhospital 旧城医院：医院由几栋互相连接的石楼组成，中庭种着能遮蔽阳光的大树。医师、治疗术士和护理人员共同照顾病人，候诊室里不时有人讨论最近的天气。这里也提供普通体检和长期休养服务。功能是治疗。事件可以进入战斗。
- sevenlantern 七灯酒馆：酒馆占据一栋老旧的三层木石建筑，门口七盏魔法灯每晚都会依次亮起。搬运工、旅人和本地居民在此吃饭喝酒，楼上偶尔有人演奏民间乐曲。这里的常客习惯互相拼桌，很少有人能独占一张大桌子。功能是休息和交谈。事件可以进入战斗。
- uppermarket 上层集市：沿山坡修建的集市分成好几层平台，每层都有遮雨棚和连通上下的台阶。来自周边村镇的人在这里出售农产，居民们边挑选边交流近来的见闻。赶集日的喧闹声能一直传到下方街区。

雾渠水镇
- mainharbor 白帆码头：宽大的河港停满来自上下游的货船和客船，岸边设置了不同高度的登船平台。水手、搬运工和旅客整日穿行其间，船只靠岸时总会引来一阵忙碌。傍晚的河面反射着港口灯火。
- sailorsinn 潮声旅馆：旅馆坐落在离码头不远的街角，客房窗户能望见来往船只。长途旅人和短暂停留的船员是这里最常见的住客，大厅里经常有人交换沿河城镇的见闻。夜深后仍能听见远处的水声。功能是休息和交谈。
- teahouse 听雨茶馆：茶馆有一处临水的半开放庭院，下雨时能清楚听见雨滴落在屋檐和河面的声音。附近居民在这里喝茶、下棋、闲谈，偶尔也有游人停下来歇脚。雨天的座位往往比晴天更难找。功能是休息和交谈。
- craftyard 联合工坊：一座宽敞的公共作业庭院连接着数间独立工坊，白天能听见各种不同节奏的敲击声。木匠、石匠和建筑工人经常在这里合作处理城镇修缮事务。年轻学徒则忙着学习如何安全使用工作空间。功能是打造和修缮。
- repairhall 公共修缮所：这里负责维护城镇的桥梁、路面、供水设施和公共建筑，墙上挂着正在进行的工程安排。测绘人员与工人不断进出，讨论哪里需要优先修补。附近居民有时会过来反映漏水和道路破损的问题。功能是修缮。
- fisherhamlet 浅湾渔村：几排低矮房屋沿着自然形成的小海湾排列，居民长期依靠捕鱼和水产养殖生活。清晨有人整理渔网，傍晚则能看到一家人坐在屋外吃饭。村里的老人对河流每个季节的变化都十分熟悉。

星林高地
- hillinn 山风旅舍：旅舍建在一处能俯瞰河谷的山坡上，宽敞的公共餐厅设有面向城镇的落地窗。登山者、旅人和想暂时远离喧闹的居民会在这里住宿。清晨的露台经常坐满欣赏日出的人。功能是休息和交谈。
- hillclinic 山麓疗养院：疗养院坐落在安静的林间坡地上，拥有宽敞的阳光房和适合慢行的庭院。医护人员照顾需要长期恢复的居民，也会安排轻松的户外活动。来探望亲友的人通常会在庭院里停留一阵。功能是治疗。
- forestgate 林地入口：一条宽阔的林间道路从石质拱门后延伸进去，附近竖立着介绍当地生态的告示。巡林员经常在入口值守，为游客说明开放区域与天气情况。周末会有不少家庭从这里进入森林散步。
- rangerstation 巡林站：巡林站由几栋木屋组成，负责森林步道维护、野生动物观察和游客安全。工作人员每天会分组进入不同林区巡查，回来后在公共厅里整理记录。有人还会带领学生认识森林里的常见植物。事件可以进入战斗。
- observatory 星象台：白色圆顶建筑立在山丘最高处，夜晚穹顶会缓缓打开，露出内部的观测区域。天文学者在这里研究星象，也定期为居民举办公开观测活动。晴朗的夜晚总能吸引不少访客。
- countrysideinn 麦穗客栈：客栈位于连接城镇与乡村的道路旁，门前有一片宽敞的草坪。赶路的商旅、农户和徒步游客常在这里吃饭休息。到了晚上，餐厅里往往有人谈论最近的天气、道路和庄稼收成。功能是休息和交谈。

三、材质和形态

只做标签和界面显示，不要因此重写战斗结算。不要装尺寸档，不要装吞噬、附身、寄生的效果。

材质四种，可多选：生物、机械、流体、灵体。不要石质。

形态：
- 生物：人形、兽形、半人马或多足、触手、虫群、植物、不定形
- 机械：局部义体、完整机体、缆线触手、多足或载具或机甲、外骨骼、无人机群
- 流体：凝胶或史莱姆、黑胶或乳胶
- 灵体：无形、能量体、影或梦

每个敌人和 NPC 记 materials 和 forms。旧标签按这个改，不要留两套：
- humanoid → 生物 + 人形
- quadruped_taur → 生物 + 半人马或多足
- tentacle_limb → 形态为触手；肉质另标生物，缆线另标机械，流体触须另标流体
- amorphous_gel → 流体 + 凝胶或史莱姆
- mech_frame 且只是身体上的义体 → 机械 + 局部义体
- mech_frame 且整具都是机器 → 机械 + 完整机体
- 黑胶、乳胶 → 流体 + 黑胶或乳胶
- 魅魔、合欢 → 生物 + 人形，不要新开材质

产卵器不升成材质。有虫群再标形态虫群。触手是形态，不是材质。

四、身体部位

只改部位名单和归类，不要重写技能和战斗公式。

八个部位：头、颈、胸、腰、生殖器官、四肢、尾巴、额外肢体。
头、颈、胸、腰、生殖器官、四肢默认存在。尾巴和额外肢体默认没有，长出来才存在。不存在的部位不能当目标，描述里也不出现。

- 口、耳、角都在头上。不要把耳朵放进颈。
- 颈只是脖颈。声带不是另一个部位。
- 腰只是腰腹。内腔不是部位。
- 生殖器官按性别描述：女、男、双性、无性。无性没有尺寸档，也不要另造能量核心。后庭不要并进生殖器官的名字。
- 四肢包含手和足。足是使用方式，不是第九个部位。
- 额外肢体只放翅膀、触手、多出来的机械臂。半人马的四足躯干是形态，不放进额外肢体。

界面上的部位名改成：头、颈、胸、腰、生殖器官、四肢、尾巴、额外肢体。

改完用几句说明：功能场所怎样通过对话进入战斗，战斗场所为什么没有功能，十八个场景里哪三处有战斗事件，材质和部位名是否已经换成上面这套。
```
