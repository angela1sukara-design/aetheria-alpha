# UI 与操作流程优化 · 2026-10-12

修改基于整理后的根目录主工程。固定都市、随机街区、词库、身体改造、战斗及存档仍共用原系统。

导航区区分故事探索与角色管理。“继续故事”和标题始终返回当前剧情；任何子页都能看到所在地、时间、保存状态，并直接保存。保存成功不切页；查看菜单和导出 JSON 不会被标记为已经保存。进入新世界或导入不同进度后，状态仍提示需要手动保存。

人物档案记住入口：从场景打开可返回场景，从人物列表打开可返回列表；从档案查看地图，可返回同一个档案。地址跳转、浏览器前进后退、Esc、页面返回使用一致的导航规则。无效人物地址显示说明，不再留下空白页。页面保留各自阅读位置。

地点行动增加故事、生活、探索、出行筛选与可用数量。筛选不改变游戏进度；进入剧情后隐藏地点筛选，只显示当前剧情选择。按钮展示已经公开的固定耗时与资源变化，并去除重复提示，不预演行动、不抽取后续故事。恢复数值受原规则上限约束。不可用操作仍可展开查看原因，展开状态在重绘时保留。

修正非事件参与者被误标为正在交谈、已认识居民仍显示空人物册说明、偏好设置覆盖上一段行动结果、生成参数错误时缺少字段定位、身体操作后键盘焦点丢失、错误反馈落在页面最下方等问题。手机菜单、阅读间距、触控大小和长文本换行同步调整，保存反馈不遮挡点击。

参考 Choice of Games 的 [ChoiceScript 独立资料页与返回故事设计](https://www.choiceofgames.com/make-your-own-games/customizing-the-choicescript-stats-screen/)，以及其 [选项与结果相连的叙事结构](https://www.choiceofgames.com/make-your-own-games/choicescript-intro/)。延续用户此前提供的 Dawn of Corruption 阅读方式，采用当前正文、当前选择、可随时查阅资料的结构。

验证入口：`npm run check`、`npm run test:ui`、`npm run test:ux`、`npm run test:worldgen:browser`、`node tests/alpha02-browser.mjs`。旧任务浏览器测试使用 `BROWSER_TEST_URL` 指向独立的已构建服务，避免覆盖离线构建。新增 UX 验证报告与截图在 `artifacts/ux-2026-10-12/`。
