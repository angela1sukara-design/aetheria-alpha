# A1/A2/A3模板实际接入

54条修订模板已全部安装：A1环境18条、A2人物30条、A3身体6条。源稿在content/prose/a-templates-v2.json，独立审定计划在production/text-slot-integration/a-templates-v1.json；普通构建校验指纹后生成运行数据。没有改变原始交付文件或把B作者稿批量标成通用approved。

新世界每个地点提供“细看周边环境”“观察在场人物”“查看身体细节”。三个专用叙事档案分别限定对应模板，仍有“换个角度看看”和免费“返回地点”。模板编号中的委托、战斗、关系等历史词不会自动执行相应业务；本批编辑后的54条都是普通观察正文，不新增战斗、交易、任务结算或关系路线。

环境入口读取该地点保存的景物实例。物件和感官从已审定的B五题材配方中限量生成，按题材、地点用途、生态和时段筛选；它们是明确保存的场景对象，不进入玩家背包、不授予设施功能。其它题材缺少适用物件时，可读取已存在设施；未知信息省略，必需物件不足时整段回退。不会从文字猜材质、容器内物或物件关系。

人物入口优先绑定所选且在场的居民，否则首次进入绑定一位在场居民，后续观察不偷偷替换对象。人物名字、职业来自当前居民；动作只采用同一居民当前日程中明确支持的“在工作/居家/休闲时段停留于此”，不把泛化日程扩写成具体工作动作。无对象或对象离场时按模板资格回退。

身体入口明确绑定玩家，人物模板的可选身体槽只读取其绑定居民。部位来自对应BodyGraph，材质来自同一部位的effectivePart；若旧定义只有organic/mechanical类别，则仅显示有机/机械材质，不猜皮肤、毛皮或鳞片。颜色定词只在该部位确有记录时挂前；无定词时干净省略。A3读取现状，不声称触摸、比较历史变化或已有双部位比较玩法。

运行时复用参考拼装器的同一份实现，生成模块由scripts/build-a-templates.mjs校验并生成，不维护另一套选词算法。制作目录的runtimeIntegrated=false继续表示该制作文件不是可直接导入的ContentPack；实际接入通过经过Schema校验的NarrativeNode.proseAssembly版本1扩展完成，仅支持general模板。

节点进入时读取真实快照并拼装一次，story.prose保存模板编号、正文、输入绑定、词条及版本。渲染只读已捕获正文，保存恢复重放输入核对输出；改字、替换出口和串对象绑定会被拒绝。正在查看时执行合法身体变化不会重写已捕获的描述，“换个角度”才读取新的身体状态。旧节点和旧存档不增加字段，不自动注入模板或重抽正文。

单世界注册54个模板节点，不按地点复制，因此20地点40居民仍受原内容上限约束。正文拼装使用独立种子排序，不消耗地图、居民和经济随机流。观察不扣资源、不推进时间、不修改NPC身份、身体或关系。

正式网页、根目录“启动游戏-双击直接运行.html”和examples/A模板-实际游戏.html包含本轮接入。旧存档保留原快照，使用新入口请新建世界。构建后执行node scripts/build-a-template-example.mjs可重建直接试玩；npm run build已包含A模板的指纹校验和运行生成。

验证入口：node --test tests/a-templates.test.ts tests/prose-assembly.test.mjs。逐条检查54模板真实拼装、同一对象归属、缺事实回退、原参考实现一致性、免费出口及存档篡改拒绝。node tests/a-templates-browser.mjs检查离线/手机显示、实际人物、玩家身体变化期间的正文锁定、保存恢复，以及从正式游戏菜单新建五种题材后使用三个入口。日志、截图与安装记录在artifacts/a-templates。
