# 以太都市思维导图

青色是已定，黄色是还没勾选，橙色是明确不做或以后再做。

- 以太都市
  - 图例
    - 绿：玩家流程
    - 红：制作模块
    - 青：已经定下
    - 黄：举例或还没勾选
    - 橙：明确不做，或以后再做
  - 玩家流程
    - 1 选择世界
      - 同时生成主线池
        - 这批不写主线正文
      - 同时生成数个大区域
      - 同时确定本世界允许的转化
        - 转化种类见材质和形态，不另起一套名字
    - 2 捏人加点
      - 输入姓名
      - 性别：女、男、双性、无性
      - 出生大区域由捏人决定
      - 按出生大区域从主线池领一条
      - 加点用哪些属性还没定死
      - 非类人角色
        - 主要内容做完再考虑。现在默认类人
    - 3 世界往下长
      - 大区域
      - 小区域
      - 场景
        - 早期例子：酒馆、医院、下水道、小巷
        - 后来改为场景可自由写，之后再删
      - 场景里生成相关的人
      - 组织挂在世界下面，和人并列
      - 道具按世界确定
        - 除基础种类外都要先设计。这一批不写道具
    - 4 探索
      - 移动
      - 调查
      - 交谈
      - 使用资源
      - 触发事件
    - 5 事件
      - NPC 事件
        - 支线任务
        - 攻略对方
          - 爱意、信任、恐惧、顺从、熟悉还没决定拆还是合成一个态度
        - 特定功能
          - 做得到才出现
          - 铁匠：打造、修理
          - 医生：治疗，清除外伤和异常
          - 旅馆酒馆：休息、吃饭、交谈
      - 触发敌对
      - 也可以直接进入战斗
    - 6 战斗
      - 双方的标签和属性决定能用什么行为
      - 胸部开发到档，才出现乳汁相关行为
      - 有触手，才能缠或抽
      - 没长出的尾巴、额外肢体不能当目标
      - 状态会关掉部分行为，例如封口不能用口
    - （否）7 胜利并且不做色色
      - 结算成长属性
      - 结算道具
      - 对方组织的态度改变
        - 喜欢或厌恶
        - 畏惧
        - 接纳或通缉
      - 区域强度记在世界上，不记在角色身上
    - 8 失败，或胜利后选择做色色
      - 匹配顺序
        - 先材质、智慧、数量、立场
        - 再形态
        - 再小标签：位置、用哪里、留下什么、怎么控制
      - 生成多段文本
      - 至少一轮
      - 不是第一次可以跳过
      - 跳过仍获得少量成长
      - 已读内容决定能不能跳过，记在存档里
      - 离开结算仍然有少量成长
    - （理智归零或主动）9 恶堕结局
      - 理智归零
      - 或玩家主动选择
      - 多段恶堕文本
      - 最后变成什么样
      - 本局结束，读档或重开
    - 进门读到的内容
      - 每个场所都有场景描述
        - 看得见什么、有什么人、人在做什么
      - 功能场所才有对话
        - 招呼
        - 使用这个场所真正有的功能
        - 一条事件，选了才进入和这个 NPC 的战斗
      - 战斗场所不写功能对话
  - 场所规则
    - 功能场所
      - 治疗、打造、休息、交谈
      - 进门是场景和对话，不是战斗
      - 只有事件才进入 NPC 战斗
      - 没选事件就不出现战斗，也不刷野怪
      - v11 里对应诊所和工坊
    - 战斗场所
      - 进门是场景描述，然后只有战斗
      - 不放治疗、打造、交谈
      - v11 里对应危险房间和首领房间
    - v11 要改的问题
      - 诊所和工坊进门就能打
      - 功能和战斗叠在同一个场所上
      - 几乎没有场景描述和对话
  - 制作模块
    - 主玩法：自由探索
    - 世界
      - 大区域 → 小区域 → 场景 → 人
      - 多种主线
      - 本世界的道具
      - 本世界允许的转化
      - 组织
    - 角色与状态
      - 见右侧角色标签和属性
    - 战斗逻辑
      - 见玩家流程里的战斗
    - 文本是汇合点
      - 吃进场所、人、道具、转化、战斗和标签
      - 不自己决定发生了什么
      - v11 战斗句的八行
        - 作者写：施事、手段、质感、反应、状态、保底句
        - 状态生成：部位描写、神态、这一击的结算
        - 部位只填部位名，不写死部位句子
    - 存档
      - 版本
      - 角色状态
      - 世界状态
      - 已读内容
      - 随机种子
      - 事件日志
      - 可迁移、可调试、可回放
    - 界面
      - 叙事区
      - 选项
      - 状态栏
      - 地图或地点
      - 日志
      - 战斗面板
  - 角色标签 · 已定
    - 材质 · 可多选
      - 生物
      - 机械
      - 流体
      - 灵体
    - 形态 · 生物
      - 人形
      - 兽形
      - 半人马或多足
      - 触手
      - 虫群
      - 植物
      - 不定形
    - 形态 · 机械
      - 局部义体
      - 完整机体
      - 缆线触手
      - 多足或载具或机甲
      - 外骨骼
      - 无人机群
    - 形态 · 流体
      - 凝胶或史莱姆
      - 黑胶或乳胶
    - 形态 · 灵体
      - 无形
      - 能量体
      - 影或梦
    - 材质和形态的关系
      - 只选机械 = 整具机器
      - 生物 + 机械 = 身上有机械部分
      - 机械义体 = 机械 + 局部义体，不是单独的材质
      - 触手是形态，可以长在任何材质上
      - 缆线触手：形态是触手，材质是机械
      - 虫群是形态，不是数量
      - 魅魔、合欢 = 生物 + 人形，不新开材质
      - 产卵器不升成材质
      - 植物和甲壳放在生物下
      - 附身不是灵体的外形
    - 智慧
      - 有智慧
      - 无意志
      - 无意志不走催眠和话术
      - 野兽、无人机、纯凝胶用无意志
    - 数量
      - 单体
      - 群体
      - 一丛触手、一群人用群体
    - 立场
      - 支配
      - 顺从
      - 切换
      - 双方都强时用切换，避免两套文本一起出现
      - 切换不自动挑边
      - 流体支配走吞噬
      - 流体顺从走附身
      - 寄生不看立场
    - 尺度改成尺寸档
      - 不再用普通、巨大、微小三个标签
      - 微小不单列，偏小用档「小」
      - 句子只订定词，不订厘米
      - r = 测量 ÷ 该形态成年基准
      - r ≤ 0.85 → 小
      - 0.85 ＜ r ≤ 1.15 → 普通，可以不加词
      - 1.15 ＜ r ≤ 1.5 → 大
      - r ＞ 1.5 → 巨大
      - 人形量身高
      - 兽形量肩高，耳尖和角不算，不设身高
      - 比谁大时比档，不比厘米
      - 半人马：人躯和兽躯各量各的
      - 场面谁更大，取两档里更高的一档
      - 流体用体积，一人高的一滩 = 1
      - 触手和额外肢体量这一肢自己的长度
      - 生殖器官直接存档，默认抄全身体量档
      - 生殖允许高一档或低一档
      - 生殖用自己的定词，不复用身高词
      - 无性没有生殖尺寸档
      - 腹下悬吊：半人马或多足，且对方体量档至少高一档
      - 四档的具体用词还没定
    - 性别与性转
      - 女
      - 男
      - 双性
      - 无性
      - 性转
      - 性转只在四档之间换，不新开材质
      - 通常改胸和生殖的描述
      - 无性不另造能量核心
    - 身体部位 · 八个
      - 头
        - 口、耳、角都在头上
      - 颈
        - 只是脖颈
        - 声带不是部位
        - 耳朵不放在颈上
      - 胸
        - 按性别描述
      - 腰
        - 只是腰腹
        - 内腔不是部位
      - 生殖器官
        - 按四档性别描述
        - 后庭不写进这个名字
      - 四肢
        - 包含手和足
        - 足不是第九个部位
      - 尾巴
        - 默认没有
      - 额外肢体
        - 默认没有
        - 只放翅膀、触手、多出来的机械臂
        - 半人马四足躯干是形态，不放这里
      - 默认存在：头、颈、胸、腰、生殖器官、四肢
      - 不存在就不能当目标，句子里也不写
      - 部位上的字段
        - 是否存在
        - 开发度
        - 部位敏感度
        - 尺寸档
        - 当前占用
        - 形态词
      - 占用
        - 封口
        - 被缚
        - 被占
        - 泌乳
        - 已改造
        - 会挡住行动的占用，同一部位同时只有一种
    - 小标签 · 用哪里
      - 口
      - 胸
      - 手
      - 足
      - 生殖
      - 后庭
      - 尾
      - 触手
      - 额外肢体
      - 这里的触手指这一次用哪一肢
    - 小标签 · 位置
      - 后入
      - 正面
      - 骑乘
      - 腹下悬吊
      - 悬吊
      - 站立
    - 小标签 · 留下什么
      - 内射
      - 外射
      - 灌入
      - 产卵
      - 泌乳
      - 吞咽
    - 小标签 · 怎么控制
      - 缠绕
      - 束缚
      - 口封
      - 五感剥夺
      - 真空封装
      - 项圈
      - 催眠
      - 真空封装时人还是自己，材质不改
    - 同化、吞噬、附身、寄生
      - 同化不是人人可用的小标签
      - 单纯吞噬
        - 只有支配的流体
        - 对方在内部，仍是自己
        - 状态：在内部
      - 融合，也就是同化
        - 只有支配的流体，并且选了融合
        - 对方不再独立
        - 变成这只流体的器官或肢体
        - 记下原来是谁
        - 材质改为流体
      - 拟态
        - 顺从的流体，或灵体
        - 呈现成另一个生物的样子
        - 外形词订那个生物，材质词仍是流体或灵体
      - 附在体表
        - 顺从的流体，或灵体
        - 宿主的身份、部位、尺寸都还在
        - 描述 = 宿主外形 + 流体或灵体材质
        - 这是状态，不进装备栏
        - 可以标记谁在选行动
        - 标记只改谁选行动，不把人变成装备
      - 寄生
        - 谁能做：流体、触手、虫群
        - 藏在宿主体内
        - 宿主外形不变，不追加材质词
        - 记下种类和来源
        - 不自动抢走行动
        - 不把人收成器官
        - 灵体不寄生
      - 感染
        - 已经被寄生的生物可以传给另一个
        - 新宿主得到同样的种类和来源
        - 原宿主不因此解除
  - 属性 · 原图有的和后补的
    - 战斗资源 · 原图已有
      - 生命
      - 理智
      - 精力
      - 体力
      - 生命归零：这次战斗失败

      - 体力：赶路、挣扎、重击、闪避

      - 敏捷
      - 智力

    - 检定候选 · 后补
      - 感知
      - 意志

      - 理智是会扣光的那一条，两者不是同一个
    - 战斗派生 · 候选，可由加点算出
      - 攻击
      - 防御
      - 速度
      - 技能强度
      - 命中
      - 闪避
      - 暴击
      - 行动点
      - 技能资源
    - 色色 · 原图已有
      - 支配 / 顺从
        - 已定，见立场
      - 性癖 / 玩法倾向
        - 是一组标签，不是一个数字
      - 敏感度
        - 可全局一条，也可拆到每个部位
    - 色色 · 后补，还没勾选
      - 快感
      - 欲望
      - 部位开发度
      - 恶堕进度
      - 当场立场
      - 快感是这一场的，离场清掉
      - 欲望只改用词和主动程度，不直接扣理智
      - 恶堕进度若只用理智归零或主动选择，可以不单列
    - 社交 · 原图已有
      - 声望
        - 建议每个大区域一条，再加一条世界级
      - 称号
        - 记下名称、来源、显不显示
      - 对每个 NPC、每个组织各一份态度
    - 社交 · 后补，还没决定拆不拆

      - 信任
      - 恐惧
      - 这个人听不听你的
      - 熟悉
      - 魅力
    - 基础 · 已定或原图已有
      - 姓名
      - 性别四档
      - 种族或出身，随世界变，现在默认类人
      - 出生大区域
    - 基础 · 还没勾选

      - 性格
        - 高傲
        - 羞怯
        - 直率
        - 精明
        - 虔诚
        - 狡黠
        - 每人一到两条。攻略和交谈会用到，这批还没定
    - 状态
      - 拘束
      - 封口

      - 快感过高
      - 在内部
      - 附身
      - 寄生
      - 受伤
      - 异常

      - 异常的名字随世界改
    - 不放进角色身上的
      - 道具、装备、钱
      - 已读内容
