# 角色标签

这是新游戏已经定下的角色标签。战斗举例属性、态度拆分、主线和道具不在这里。

一个角色可以同时有多个材质、多个形态、一组小标签。句子只读标签和尺寸档，不读厘米。

## 1. 材质

可多选。

| 标签 | 说明 |
| --- | --- |
| 生物 | 血肉、植物、甲壳都在这档。兽形、虫群、植物是它下面的形态 |
| 机械 | 整具机器或身上的机械部分 |
| 流体 | 会流动、会包裹的身体。黑胶和凝胶都在这档 |
| 灵体 | 无形、能量、影或梦 |

石质、结晶、魔像不做。

机械义体不是材质。它是「机械」加形态「局部义体」。只选机械，是整具机器。生物加机械，才是身上有机械部分的人。

魅魔、合欢仍是生物加人形，不新开材质。

## 2. 形态

形态不单独当材质。触手可以长在生物、机械、流体或灵体上。

| 挂在 | 形态 |
| --- | --- |
| 生物 | 人形、兽形、半人马或多足、触手、虫群、植物、不定形 |
| 机械 | 局部义体、完整机体、缆线触手、多足或载具或机甲、外骨骼、无人机群 |
| 流体 | 凝胶或史莱姆、黑胶或乳胶 |
| 灵体 | 无形、能量体、影或梦 |

虫群是生物下面的形态，不拿来表示「有几个」。缆线触手若要寄生，走触手的行动，材质仍是机械。

液态金属不单列，需要时并进流体。附身不是灵体的一种外形。

产卵器不升成材质。有虫群再标形态虫群。

## 3. 智慧

| 标签 | 说明 |
| --- | --- |
| 有智慧 | 可以催眠，也可以使用话术 |
| 无意志 | 不走催眠和话术。野兽、无人机、纯凝胶用这档 |

## 4. 数量

| 标签 | 说明 |
| --- | --- |
| 单体 | 一个生物 |
| 群体 | 一丛触手、一群人。和虫群形态无关 |

## 5. 立场

| 标签 | 说明 |
| --- | --- |
| 支配 | 流体走吞噬 |
| 顺从 | 流体走附身 |
| 切换 | 双方支配和顺从都强时用这一档，避免同一场配上两套文本 |

切换不自动挑边。寄生不看立场。

## 6. 尺度与尺寸

不再使用「普通 / 巨大 / 微小」三个标签。

巨大和偏小改由尺寸档表达。腹下悬吊要求对方体量档至少比自己高一档，并且形态含半人马或多足。微小不单列，偏小用尺寸档「小」。

句子只订定词，不订厘米。每种形态用自己的尺子量，再除以该模板的成年基准。

| 相对基准 r | 档 | 句子 |
| --- | --- | --- |
| r ≤ 0.85 | 小 | 用该形态的「小」定词 |
| 0.85 ＜ r ≤ 1.15 | 普通 | 可以不加定词 |
| 1.15 ＜ r ≤ 1.5 | 大 | 用该形态的「大」定词 |
| r ＞ 1.5 | 巨大 | 用该形态的「巨大」定词 |

| 形态 | 量什么 | 基准 | 句子订哪张词 |
| --- | --- | --- | --- |
| 人形 | 头顶到脚 | 该出身的成人中位身高 | 人形身高词 |
| 兽形 | 肩高。耳尖和角不算 | 该兽形的成人肩高 | 兽形词。比谁大时比档，不比厘米 |
| 半人马 | 兽躯肩高，人躯身高，各量各的 | 两个基准 | 人躯和兽躯各订各的词。场面谁更大，取两档里更高的一档 |
| 流体 | 摊开的体积，折成相当于几个成年人身高的一滩 | 一人高的一滩 = 1 | 流体词。不出现身高 |
| 额外肢体、触手 | 这一肢的长度 | 这一肢自己的基准 | 肢体词。不拿来当全身身高 |
| 生殖器官 | 不量厘米，直接存档 | 默认等于全身体量档，允许高一档或低一档 | 生殖词。无性没有这档 |

四档的具体用词还没定。

## 7. 性别与性转

性别四档：女、男、双性、无性。

性转只在这四档之间更换，不新开材质。通常改到胸和生殖器官的描述。无性没有生殖尺寸档，也不另造能量核心。

## 8. 身体部位

八个部位：头、颈、胸、腰、生殖器官、四肢、尾巴、额外肢体。

头、颈、胸、腰、生殖器官、四肢默认存在。尾巴和额外肢体默认没有，长出来才存在。不存在的部位不能当目标，描述里也不出现。

| 部位 | 怎么归 |
| --- | --- |
| 头 | 口、耳、角都在头上 |
| 颈 | 只是脖颈。声带不是另一个部位，耳朵不放在这里 |
| 胸 | 按性别描述 |
| 腰 | 只是腰腹。内腔不是部位 |
| 生殖器官 | 按女、男、双性、无性描述。后庭不写进这个部位的名字 |
| 四肢 | 包含手和足 |
| 尾巴 | 默认不存在 |
| 额外肢体 | 只放翅膀、触手、多出来的机械臂。半人马的四足躯干是形态，不放在这里 |

足是「用哪里」的用法，不是第九个部位。

每个已有部位可以另记：是否存在、开发度、部位敏感度、尺寸档、当前占用、形态词。占用包括封口、被缚、被占、泌乳、已改造。同一部位同时只有一种会挡住行动的占用。

## 9. 小标签

先匹配材质、智慧、数量和立场，再匹配形态，再用这些小标签。

### 用哪里

口、胸、手、足、生殖、后庭、尾、触手、额外肢体。

足和口、胸、手并列。触手在这里指这一次用哪一肢。形态里的触手指长成那样。

### 位置

后入、正面、骑乘、腹下悬吊、悬吊、站立。

### 留下什么

内射、外射、灌入、产卵、泌乳、吞咽。

### 怎么控制

缠绕、束缚、口封、五感剥夺、真空封装、项圈、催眠。

真空封装时人还是自己，材质不因此改掉。

## 10. 同化、吞噬、附身、寄生

同化不是人人可用的小标签。它只发生在流体、立场为支配、并且结果选了融合的时候：对方不再独立，变成这只流体的器官或肢体，材质改为流体。

封装和同化分开。封装用「真空封装」，人还是自己。

| 谁 | 行动 | 结果 |
| --- | --- | --- |
| 流体 · 支配 | 吞噬 | 单纯吞噬：对方在内部，仍是自己。状态记「在内部」 |
| 流体 · 支配 | 吞噬 | 融合，也就是同化：变成这只流体的器官或肢体，记下原来是谁 |
| 流体 · 顺从 | 拟态 | 自己呈现成另一个生物的样子。外形词订那个生物，材质词仍是流体 |
| 流体 · 顺从 | 附在体表 | 留在宿主体外。宿主的身份、部位、尺寸不变。描述是宿主外形加流体材质 |
| 灵体 | 拟态或附在体表 | 与流体附身同一条状态。材质词换成灵体。不进装备栏，也不寄生 |
| 流体、触手、虫群 | 寄生 | 藏在宿主体内。宿主外形不变，不追加材质词。状态记下种类和来源 |
| 已被寄生的生物 | 感染 | 把同一条寄生传给另一个生物。新宿主得到同样的种类和来源。原宿主不因此解除 |

附身是状态，不是装备。装备栏只放真正的道具。附身可以再带一个标记：行动仍由宿主选，或改由附身者选。这个标记只改谁在选行动。

寄生不自动抢走行动，也不把人收成器官。灵体不寄生。非流体不能把对方整个吞进去。

## 11. 不做

| 不收入 | 原因 |
| --- | --- |
| 石质、结晶、魔像 | 已决定不做 |
| 普通 / 巨大 / 微小三个标签 | 改由尺寸档换定词 |
| 非流体的吞入 | 把对方装进自己里面，只留给支配的流体 |
| 灵体寄生 | 寄生只开放给流体、触手、虫群 |
| 附身进装备栏 | 附身是状态 |
| 孕 | 产卵已经覆盖虫和寄生留下的结果 |
| 疼痛、电击、窒息、滴蜡 | 现有束缚和封装够用 |
| 公开 | 多一个观众，不改变身体和做法 |
| 液态金属单独成形态 | 并进流体 |
