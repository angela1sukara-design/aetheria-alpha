# 墨卷 UI 接入 · 2026-10-13

基于用户提供的 `mojuan-folio.zip`，将书页、故事卡、对白、属性栏、对面栏、封面与移动抽屉接入根目录最新游戏。原框架的 React/Tailwind 演示组件移植到现有 TypeScript 界面，继续使用本地 ESM 服务与独立离线 HTML。设计参考原包保存在 `docs/design-sources/mojuan-folio.zip`。

## 试玩

直接打开 `dist/Aetheria-Folio.html`。封面显示当前真实地点和时间；“翻开书页 / 继续旅程”进入已有进度。“探索新世界”打开实际世界生成页。原 `dist/Aetheria-Alpha-0.2.html` 保留为同内容入口，服务器仍使用 `localhost:4173`。识别新版：左上显示“墨卷 / 以太都市”，有封面和黑白书页。

## 结构与真实功能

| 墨卷组件 | 接入后的用途 |
| --- | --- |
| 封面 | 显示实际进度，进入当前书页或世界生成 |
| 书页 | 当前地点、故事、行动结果；通常最多四个分类入口 |
| 故事卡 | 探索、交谈、生活和出行；每页最多六张可用卡，先查看条件与消耗，再确认执行 |
| 白台 / 交锋 | 使用引擎当前事件节点、真实选择与战斗回合；右侧显示参与者或敌方状态 |
| 属性栏 | 真实零钱、精力、生命、体力、理智、技能资源与身体能力；变化随行动刷新 |
| 对面栏 | 当前人物的身份与关系，或当前敌人的体况、意图和剩余行动点 |
| 手册 | 背包、装备与消耗品、地图、人物关系、任务、图鉴、记录、身体改造、内容扩展 |
| 存档 | 卷一、卷二、卷三分别读写 IndexedDB 中的完整游戏状态；支持原 JSON 导入导出 |
| 阅读设置 | 正文字号、即时或逐字揭示、减弱动效、标签来源调试；保存在本机 |
| 手机抽屉 | 查看同一份真实属性和人物 DOM，关闭后回到原书页；横屏显示属性栏 |

卷一沿用原手动槽；独立世界示例沿用各自原槽。卷二、卷三使用独立槽键，保存或读取后记住最后使用的槽。切换槽位只查看，不加载或覆盖进度。换浏览器、服务器地址或离线入口时，可以先导出 JSON 再导入。

卡片预览和分页只改变显示。正式行动继续走 `ActionExecutor`；时间、随机流、身体、关系、奖励和故事节点由原引擎结算。菜单与卡片返回保留对应入口和滚动位置。数字键选择书页入口或剧情选项；逐字阅读时空格显示全文；Esc 关闭抽屉或返回卡片列表。

保留最新版的中世纪异世界快速生成、战败后八玩法、训练、六槽装备、消耗品、经营与扩展导入。试玩快捷入口集中在“菜单 → 探索新世界”，主书页以叙事为中心。标签来源调试在“设置 → 开发与内容”中开启，常规正文标签呈现为文字。

## 接入时修复

- 新安装的通用 taxonomy Tag 与旧世界选择别名冲突，导致世界构建和生成失败。世界题材的旧 ID 兼容移至世界选择边界，保留通用规范 Tag，原校验规则保持严格。
- 生成结束后战败试玩按钮仍保持忙碌禁用状态；完成忙碌状态切换时同步按钮。
- 快速切换存档槽时旧异步响应覆盖新槽信息；响应按槽键核对，并先禁用读取。
- 字号 / 揭示控件误把 body 的 data 属性当成按钮监听；限定真实按钮，避免复选框点击被冒泡重置。
- 标签来源浮层按实际尺寸约束位置，避免窄屏超出可视区域。
