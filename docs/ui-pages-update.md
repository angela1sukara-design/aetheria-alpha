# UI 与子页更新 · 2026-10-11

后续优化见 [2026-10-12 UI 与操作流程](ui-ux-2026-10-12.md)：资料入口返回、快捷保存、行动筛选和显示问题修正。

本轮 UI 已合入主工程和 v0.2.1 词库版，保留新版词库加载、居民服装与性情、世界生成及原存档流程。参考用户提供的 Dawn of Corruption 游戏中固定状态栏、单一剧情正文与当前选项的阅读结构，保留以太都市现有视觉风格和游戏规则。

地点名改为小型导航栏。进入地点时展示环境介绍；执行行动后，主标题和正文显示该次行动及其结果。NPC 对话、一般事件、战斗和私人互动显示各自的正文与选择，不继续堆叠地点介绍。需要回看时点击“地点介绍”。普通行动和居民交谈可返回地点行动页；进行中的事件、战斗和私人互动只能从实际剧情选项退出。

地图、身体、人物、存档、记录、任务、背包、发现、内容偏好和世界菜单均进入主区独立子页，保留角色状态与全局菜单。地址记录当前菜单；支持刷新、浏览器前进/后退、页面返回按钮和 Esc。人物列表可进入单个人物档案，档案内沿用真实日程、记忆与可用交谈入口。身体操作留在身体页并即时显示结果；人物交谈与地图旅行则返回对应剧情页。

不可用操作折叠为“暂不可用”，展开后可查看具体条件。偏好设置从行动列表移入内容偏好页。删除重复的通用操作提示，补充人物卡直接交谈入口。重新调整桌面与手机的字号、间距、选项宽度和焦点位置。

界面跳转只影响显示状态，不直接修改时间、随机流、关系、战斗回合或剧情节点；规则和存档格式保持既有实现。浏览器历史用于菜单导航，不用于撤销已经执行的游戏行动。刷新只能恢复已手动保存的游戏进度。

试玩入口：`dist/Aetheria-Alpha-0.2.html`；离线随机街区：`dist/WorldGenerator-Seed-7.html`、`dist/WorldGenerator-Seed-42.html`。

验证：`npm run check`、`npm run test:ui`、`npm run test:worldgen:browser`、`node tests/alpha02-browser.mjs`，以及使用独立测试地址的 `npm run test:browser`。新页面流程与截图见 `artifacts/ui-refresh/`；现有浏览器任务流程使用更新后的导航定位。词库候选、居民服装与性情格式的回归断言继续保留。
