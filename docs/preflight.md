## 环境与最小方案

Node v24.19.0、npm 11.9.0、Git 2.51.1；安装并锁定 TypeScript 5.9.3、Playwright 1.62.1。新工程位于独立的 `aetheria-alpha-0.1` 目录并初始化独立 Git 仓库。

采用原生 ESM + TypeScript + DOM/CSS，不依赖前端框架。构建只移除类型并转换模块扩展名，独立复制 JSON 包和 CSS。不把世界内容写进 HTML，不绑定外部 AI。
