# 生成器 v0.2 审计与实施范围

2026-10-11，基线 `79fd967`。接手时工作区干净，无其他任务的未提交修改。基线源码归档在交付目录，开发在独立 `codex/world-generator-v0.2` 分支。

现有生成器、快照、日程模拟、Registry、身体、TF、行动、事件与存档均已实现，继续复用。词条生产工具和可选正文槽工具独立保留。

发现的问题及最小方案：

- 只有两个生态和少量模板；扩充独立参考包及生成专用居民内容包，保留固定世界的六包清单。
- 随机地点共用通用日常按钮；新增受校验的 activity 模板，编译成既有资源、身体条件和时钟效果。
- 每地点只有一个生成事件；支持有界、去重的本地事件池，仍由 Storylet 冷却与选择逻辑触发。
- 居民只能和随机事件同时被选中；复用遭遇入口，增加不触发事件的浏览选项。
- 工作分配忽略诊所和住宅等合法职业地点；只考虑实际兼容的地点，并先覆盖再重复分配。
- 独立抽取地图坐标可能重叠；使用确定性的不同网格和小幅偏移。
- 生成居民模板时间到 1439，旧街区重校验会在23:59错误清除选中居民；生成世界改按保存的实际位置检查，固定世界沿用原模板窗口。
- 存档校验只接受生成器0.1；明确支持0.1与0.2，保留真实已发布0.1存档压缩测试样本，读档不重生成。

本轮不实现完整经济、政治、文明演化、个人长篇攻略、NPC自主TF或实时AI。词条交付后再以独立审核适配步骤将素材绑定到描述/对白字段，不让自由文本改变世界状态。

M1：生成接口与边界修补完成；类型检查、174项自动化测试、模块和离线构建、发行检查通过。已保存可运行 M1 构建归档；后续 M2 扩充默认内容并实玩验收。

M2：默认参考库扩展到152模板（6生态、60地点、42事件、12组织、21活动、11NPC引用），另加入9个生成专用居民原型。生成源加载额外内容包，固定世界仍为原六包清单。180项自动化测试、生成器10组浏览器流程、原Alpha0.2的15组浏览器回归通过；最终源码与可运行版本一并归档，详见 `worldgen-v0.2-acceptance.md`。
