# 以太都市：深渊重塑 · Alpha 0.1 第二阶段

这是独立 TypeScript 工程的第二阶段更新。在原有三地点日常玩法之上，增加真实 BodyGraph、自由塑形和分阶段机械尾改造。旧 HTML Demo 不参与构建、不兼容其存档；本工程第一阶段官方存档可升级。

## 启动试玩

需要 Node.js 24 或更新版本。交付包含已构建的 `dist/`，试玩不需要安装依赖。

1. 关闭上一版游戏的服务器命令行窗口。
2. 把本包解压到新的文件夹。
3. Windows 双击 `start_game.bat`，服务成功启动后会打开浏览器。

也可以运行：

```sh
node scripts/serve.mjs --built
```

浏览器地址为 `http://localhost:4173/`。保持服务器窗口开着。端口被占用时，先关闭上一版窗口再启动；启动失败不会自动打开旧版页面。不能直接双击 `index.html` 使用 `file://` 加载模块与 JSON。

## 新内容试玩路线

1. 公寓打开「身体」，换成狼耳或猫耳；时间与零钱不变。
2. 公寓 → 主街 → 改造诊室，选择「了解机械尾改造」。可继续看说明，也可无代价退出。
3. 支付 18 币开始改造。已有生物尾时需先处理现有尾部。
4. 等候 15 分钟：身体图加入「待校准的机械尾」，此时没有尾部抓握能力。
5. 打开身体面板暂停。做日常行动会推进世界时间，但不会推进暂停的改造。耳型等无冲突部位仍能塑形。
6. 保存、刷新、读档，确认身体与暂停进度保留。继续改造，累计活动时间45分钟后得到抓握能力。
7. 回主街 → 集市，执行「用机械尾协助分拣」，真实改变时间、精力和零钱。移除尾部后该工作不可用。

取消会释放预约，费用不退、已完成结构保留；可在身体面板另行移除试装部件。以上文案/数值/普通部件开放范围均为 **PROPOSED 测试切片**，未冻结最终世界设定。

## 存档

仍为单槽手动存档。刷新恢复最近一次手动保存；未保存的操作不自动写入。JSON 导入只改变当前游戏，点击保存才覆盖手动槽。

同一浏览器、同一地址和端口下，会读取上一版的 IndexedDB。若换了浏览器或地址，请从上一版导出 JSON，再在本版导入。

第一阶段原始 core/world 包的精确存档可升级到 schema 2：保留地点、时间、钱、标记、事件原文、RNG和事务账本，只新增初始身体与空TF队列。升级读取不覆盖原记录，保存后才写入新版。新档不能返回第一阶段引擎读取。未知旧包、包变更、损坏存档保留并隔离；尚无通用内容包迁移。

## 开发和验证

```sh
npm ci
npm run check
npx playwright install chromium
npm run test:browser
```

实际验证：56项规则/存档测试、类型检查和构建产物执行通过；24项真实 Chromium 浏览器检查通过，包括 IndexedDB、JSON、TF及390px布局。详见 `docs/phase-2-report.md` 与 `artifacts/stage2-check-output.txt`、`stage2-browser-output.txt`、`browser-results.json`。

标准浏览器下载在本环境失败，实际测试使用独立测试环境的 Chromium 153.0.8010.0。测试脚本支持 `BROWSER_EXECUTABLE_PATH` 和 JSON 格式的 `BROWSER_ARGS_JSON`，可指定已安装的浏览器；`BROWSER_FONT_CSS` 仅用于缺中文字体的测试环境。交付不包含该浏览器或测试字体，不增加游戏运行依赖。

## 模块边界

| 目录 | 职责 |
| --- | --- |
| `src/core` | 基础协议与身体/TF类型；无具体世界人物 |
| `src/content` | schema、依赖/引用/能力/模板拓扑检查、只读Registry |
| `src/engine` | 唯一行动事务、图补丁、TF队列/时间边界、事件、RNG、纯选择器 |
| `src/persistence` | schema 2、精确旧档升级、图/队列/来源校验、IndexedDB/JSON |
| `src/ui` | 身体/阶段显示与行动入口；不写玩法状态 |
| `content/core`, `content/world` | 第一阶段原包保留，三个地点与原有日常玩法 |
| `content/reshaping` | 独立命名空间的诊室、身体部件、图补丁、TF、行动与咨询事件 |
| `tests` | 回归与新规则、存档、真实浏览器测试；旧档fixture |
| `docs` | 阶段范围、协议与结果，历史报告保留 |

地图与正文内容从 `content/index.json` 加载，诊室路线通过原包公开Hook追加。没有NPC/姿势/战斗假按钮。对应模块仍独立预留，未实现完整NPC、Slot/装备、InteractionScene、战斗、Storylet或完整EventGraph。本阶段不等于M1/M2/M3全部完成，也没有发布或覆盖旧试玩站。
