# 可选文本槽接入工具包 v0.1

这是给编程 AI 的接口接入包。它包含当前 Alpha 0.2 的真实槽位格式、一个可加载的中性测试内容包、一个可导入的占位文本包，以及自动化验证。没有露骨正文或要求生产这类正文的指令。

工程基线：`daf1a45`，游戏版本 `0.2.0-alpha`。本包不修改默认内容清单，不给现有人物补写情节，不代表成人玩法已完成。示例只验证已有 `adult_optional` 显示开关。

## 直接交给其他 AI

把整个压缩包交过去，让它先读 `交给编程AI.md` 和 `01-当前接口.md`。如果需要它实际修改代码，还需提供当前工程源码；本压缩包不包含整套游戏。一次完成技术接入和验证后统一交付，无需每个槽位单独确认。

| 文件 | 用途 |
| --- | --- |
| `交给编程AI.md` | 可直接使用的工程任务指令 |
| `01-当前接口.md` | 已实现的数据契约、加载方式和限制 |
| `02-待补接口与验收.md` | 按现有框架补缺口的范围与验收要求 |
| `examples/slot-content-pack.json` | 注册测试 NPC、事件、入口、出口与文本槽的完整内容包 |
| `examples/placeholder-text-pack.json` | 只替换正文的中性文本包 |
| `verify.test.mjs` | 调用真实工程加载器、执行器和存档器的测试 |
| `VERIFICATION.md` | 本次验证结果 |

## 在工程内验证

需要 Node.js 24 或更高版本。在工程根目录运行：

```powershell
node --test production/text-slot-integration/verify.test.mjs
```

若压缩包解压在工程以外，指定源码所在目录：

```powershell
$env:AETHERIA_REPO = 'D:\desktop\nsfw\aetheria-alpha-0.1'
node --test .\verify.test.mjs
```

验证过程在内存中加载示例，不写入正式内容清单或玩家存档。只安装占位文本包而没有先注册示例槽位，会被正确拒绝。

## 资料和玩法的边界

基础词条仍放在独立的 `production/lexicon-authoring/`。文本槽是特定事件节点的显示接口，不能把数千条素材逐一注册成剧情事件。词条被收录、文本包被校验、玩法已经实现，是三个不同状态。

`adult_optional` 是当前已存在的接口枚举，不是自动审核结论。JSON 格式通过只说明结构合格；正文意义需要单独审核。不要自行添加 `explicit` 等未实现字段并声称可运行。
