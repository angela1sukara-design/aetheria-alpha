# 待补接口与验收要求

本页是未来工程修改的清单，**不是已经完成的功能说明**。本轮只提供规范、可加载中性示例与验证，不改运行时协议。

## 最小通用修补

| 问题 | 最小解决方向 | 必要负例 |
| --- | --- | --- |
| 同节点多个槽时取第一个，结果含糊 | Registry 建立时按 `(eventId, nodeId)` 检查唯一性 | 两个不同 ID 绑定同一节点必须报错 |
| 槽与事件参与者未强制一致 | 明确 participants 是否必须包含 player；非玩家集合须与事件参与者一致 | 多出、遗漏、重复或不存在的参与者失败 |
| 声明出口与实际行动可能不一致 | 校验出口属于 owner 节点、context 一致、真实效果能到达声明节点/退出；保留每个选择节点的无条件出口 | 其他节点按钮、其他事件按钮、错误 nextNodeId 不能通过 |
| NPC 成年资格只有物种门槛 | 统一资格函数，年龄已知且至少 `max(18, species.adultAgeYears)`；智慧资格仍需满足 | 17 岁但物种门槛较低、未知年龄、未成年、非智慧角色均失败 |
| 上下文和显示资格可能分别实现 | 注册验证、显示和导出调用同一只读身份解析与资格接口 | 开关开启不能覆盖身份或年龄失败 |

修改校验前先扫描正式内容中是否有不符合新约束的对象，报告具体 ID 与最小修正，不自动改写人物剧情。新的错误信息应指出包、槽和字段，失败不得留下半个 Registry。

## 动态 NPC 接口边界

当前 `participants` 使用固定 NPC 定义 ID，`writingContext()` 和文本变量替换直接调用 `Registry.npc()`。世界居民实例已经有自己的身份数据，但没有接到此槽协议中。

未来可采用版本化的参与者引用，例如区分 `fixed` 定义引用与 `resident` 世界实例引用，并提供统一只读 `resolveParticipant(state, registry, reference)`。这只是设计方向，不是当前 JSON 字段。

解析结果必须绑定同一世界内已保存的稳定身份，提供显示名称、年龄资格来源、现有关系/记忆、当前位置及实际可用的身体数据。缺少身体、年龄或实例时明确返回缺失；不得生成替身、重新抽取姓名或以描述推导器官。存档迁移应保留旧的固定 NPC 引用，避免新内容加入后改变已经认识的人物。

## 描述与执行条件分开

`sceneRequirements`、`before`、`after`、`purpose`、`requiredBeats` 当前是创作说明。未来若要增加实际限制，使用可验证的结构化规则与既有事件/行动执行器。正文只负责呈现已成立的事实；同意、身体变化、资源占用和关系里程碑不能由正文宣称后自动成立。

BodyGraph 当前支持的部位和接触能力有限。素材库可以提前收录尚未实现的外观描述，但不得在槽示例中假装这些部位和玩法已实现。需要身体能力扩展时另做身体协议、TF 和存档测试。

## 事件评级与版本

当前 `adult` 事件加载被统一拒绝；保留该行为。若以后设计资格协议，应有显式能力版本、统一的入口与恢复检查、关闭偏好后的安全显示和退出路径，并覆盖旧包和旧档兼容。不要通过删除守卫、放宽物种年龄或改写评级解除限制。

## 存档与内容包

仅换 TextExpansion：游戏状态不变，没有正文时回退。新增完整 ContentPack：包集合发生改变，必须通过现有 SaveCodec 验证，不能承诺任意旧档直接兼容。示例存档只验证同一完整包集合下的恢复。

生成世界保留生成时的包信息和快照语义；后续新参考素材不能反向重生成已保存世界。需要新引用格式时，应先定义迁移或隔离策略，再改变存档结构。

## 当前工具包的验收范围

`verify.test.mjs` 验证真实工程下的以下行为：

1. 测试槽通过完整内容包注册，入口可执行、正文可显示、出口可退出。
2. 默认关闭、身份未建立、玩家年龄不足、所需事实为假和无文本包时，都使用中性回退。
3. 未知年龄的 NPC 或动态 NPC 实例不能冒充固定参与者注册。
4. 未登记槽、未允许变量、额外效果字段和新造评级不能通过正文包校验。
5. 现有 adult 事件拒绝行为保持有效。
6. 文本包的生命周期和重复渲染不改变权威状态或 RNG。
7. 同一内容包集合中保存再恢复，仍在原事件节点，身份与状态不变；缺正文只改变显示。
8. 上下文只报告实际参与者、flags 和 scene，不虚构身体或接触。

这些测试不证明自然语言内容正确，也不证明上表尚未实施的修补已经实现。工程 AI 完成新接口后，应新增对应负例并更新本页状态。
