# 赛博主线：站上顶点

状态：保留为独立赛博示例。默认生成世界已经使用[六类街区各自的任务](../neighborhoods/README.md)，不再加载本包。

本目录保留离线作者源文件：

- `quest-tree.json`：按用户指定结构保存的完整主线树、七条支线及关系规则。
- `execution.json`：可执行选择的明确数据，包括玩家正文、按钮、条件、时间、精力、完成与记忆。

运行 `npm run quests:build` 生成 `content/generation/cyber-apex.json`；完整构建也会自动执行。源文件中的自然语言不会在游戏运行时被解释成规则，不调用 AI。

本包的首富和军阀各四阶段，相关支线可跳过；居民在场时才可共同完成支线。通过生成器 `questContent` 参数显式传入本包可独立验证。默认入口及种子 7、42 离线 HTML 使用六类街区目录。

新功能包括生成时的地点与居民稳定绑定、五类轻量玩家关系、动态居民任务记忆、分别追踪的 Journal，以及快照保存与恢复。旧存档保留原世界内容，新主线通过新生成世界体验。

接入协议、限制和验收命令见 [赛博主线接入说明](../../../docs/reference/cyber-apex-integration.md)。
