总目标10700条，58类，214批；这些是计划数量，本轮不冒充已经完成海量正文。每批50条可控制上下文长度、方便追踪来源与补交。

|阶段|批数|素材数|执行目的|
|---|---:|---:|---|
|trial 试产|10|500|先统一格式和审稿口径|
|coverage 分类覆盖|48|2400|补齐其余分类的首批|
|expansion 主题扩充|156|7800|对同类更换主题与视角，逐步积累|

试产选择姓名、性格、职业、服装、环境细节、天气、工作动作、开场、回应、TF适应各一批；这些只是优先制作的素材，不代表都已接入玩法。production-plan.json中每个任务都有stage字段；后续用management/index.json查看领取和完成情况。

## 多AI分工方式

可让任意模型的A工作单元负责NPC，B负责身体外观，C负责世界环境，D负责日常与对白；也可把同类的不同批次分给多个AI，分别处理不同生活主题。模型名称不影响格式，不为不同平台维护多套Schema。每个工作单元有独立producer名称，不以模型名充当唯一身份。

首批通过格式与风格审稿后再大批派发。每批收录前检查全库精确重复；可用“npm run lexicon -- context npc-trait”生成该分类的续写摘要，随下一任务附给AI，避免重复名称与意象。摘要只含词库素材，不包含游戏隐藏剧情。

首期完成后使用extend分配b0005、b0009等各类下一编号，继续50条一批，不改旧ID。新增主题可以是新的材料、生活环境、表达距离、感官焦点或社会处境，不要求AI设计规则。遇到同义堆积应先改写主题，而不是只提高数量。
