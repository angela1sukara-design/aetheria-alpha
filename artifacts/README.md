# 验证与工作记录

此目录不是开发工程。文件按原位置保留，方便历史报告、测试脚本和发布元数据追溯。

| 位置或命名前缀 | 内容 |
| --- | --- |
| `check-*`、`browser-*`、`stage2-*`、`stage3-*` | 早期规则、存档、浏览器流程、截图和验收日志 |
| `alpha02/`、`alpha02-*` | Alpha 0.2 验证与阶段记录 |
| `worldgen/`、`worldgen-*` | 世界生成器验证、截图、打包和解压核验 |
| `lexicon-*` | 词库接入、审查及交付核验 |
| `ui-refresh/` | UI 子页与主区流程验证 |
| `text-slot-package-qa-*` | 文本槽外发包核验 |
| `*.bundle`、`*-source.zip` | 当时留下的恢复或源码快照 |
| `*.mjs` | 当时使用的调试／交付辅助脚本，非游戏启动入口 |

`*-release/`、`*-archive-qa/` 等目录可能含复制的 `src/`、`dist/` 或完整解压包，用于核验发布；继续开发使用根目录源码。正式供用户取用的交付见 [deliverables/](../deliverables/README.md)。

部分测试会在这里重新生成结果；生成新结果不会更新已有发布包里的验证记录。本次整理不删除历史证据。
