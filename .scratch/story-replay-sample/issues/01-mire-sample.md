# 01：交付同一故事的真实属性与跳过结算小样

规格：[spec.md](../spec.md)。车道：`mechanism`；沿用当前工作区已有实现，不扩大引擎改动。

交付三个可以直接运行的黑沼故事入口，并记录实际世界、属性和身体结果，让玩家能核对“属性影响故事”和“跳过保留后果”。

- [x] 三个入口使用正式游戏、有效存档与真实生成世界。
- [x] 同一世界高低体力对照；另一世界展示不同实际材质。
- [x] 零资源可推进，覆层与残迹真实写入。
- [x] 正常继续与跳过结算相同，在下一选择停下。
- [x] 付费挣脱、清理与带着现状离开能在界面完成。
- [x] 保存与读取不重抽，桌面与移动界面可操作。
- [x] 交付安装记录与 Evolver 经验草稿，标明工具使用情况与验证边界。
- [ ] 用户认可叙事、节奏及选择，确认值得继续扩展。
